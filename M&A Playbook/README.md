# Avera — M&A Playbook

A living knowledge base built from deal experience. Add to this over time as new situations arise, patterns emerge, and lessons are learned.

---

## What's Here

| File | Description |
|---|---|
| `MA-Cheat-Sheet.md` | Core reference: term sheet anatomy, earnouts, buyer types, market benchmarks, common pitfalls |
| `Sell-Side-Process.md` | Full sell-side process walkthrough — readiness through close, phase by phase |
| `Engagement-Structures.md` | How to scope, price, and structure fractional M&A engagements; handling the referral-fee trap |
| `Cap-Table-and-Ownership.md` | Equity types, blocking/approval/information rights, preference stack, waterfall math with examples |

**Coming soon (add as needed):**
- `Diligence-Management.md` — data room setup, diligence tracker, managing requests
- `Integration-Playbook.md` — post-merger integration, Day 1 planning, culture alignment
- `Partnerships.md` — structuring and closing strategic partnerships
- `Sector-Notes/` — vertical-specific considerations (EdTech, SaaS, healthtech, consumer, etc.)
- `Deal-Case-Studies/` — anonymized notes from past or client deals

---

## How to Use This

- **Before a client call:** Pull up the relevant section to refresh on terms and market norms
- **During an engagement:** Use as a quick-reference while reviewing term sheets or managing diligence
- **After a deal:** Add lessons learned, new patterns, or sections that were missing
- **Building the practice:** Draw from this to create client-facing materials, one-pagers, or proposals
